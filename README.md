# Django Password Generator & Vault

Учебный проект менеджера паролей с генератором паролей на Django.
Пользователи регистрируются, хранят свои учётные записи (сайт, логин, пароль)
для разных сервисов и могут генерировать надёжные пароли прямо в форме.

## Функциональность

- Регистрация, вход и выход пользователей
- Генератор паролей: настраиваемая длина (4–128 символов), цифры, спецсимволы
- Генерация пароля на основе модуля `secrets` (криптографически безопасная)
- Учётные записи: сайт, логин, пароль, дата создания и дата изменения пароля
- Создание, редактирование, удаление учётных записей (только владельцем)
- Пагинация списка учётных записей
- Автоподстановка сгенерированного пароля в форму создания/редактирования

## Технологии

- Python 3
- Django
- SQLite
- python-dotenv (переменные окружения)

Установка и запуск
Клонируйте репозиторий:
```bash
git clone https://github.com/vladimirperov85/Django-password-generator.git
cd Django-password-generator
```

Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate
```

Установите зависимости:
```bash
pip install django python-dotenv
```

Создайте файл .env в корне проекта:
```
SECRET_KEY=ваш_секретный_ключ
```

Примените миграции:
```bash
python manage.py migrate
```

Создайте суперпользователя (для доступа к админке):
```bash
python manage.py createsuperuser
```

Запустите сервер разработки:
```bash
python manage.py runserver
```

Откройте в браузере: http://127.0.1:8000/
⚠️ Важно
Проект учебный. Пароли хранятся в базе данных в открытом виде —
в реальном менеджере паролей их необходимо шифровать (например, с помощью
cryptography.fernet).
